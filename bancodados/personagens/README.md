# Mídia dos personagens

Cada personagem possui `audios/`, `gifs/` e `stickers/`.

Padrão visual dos GIFs/logos: formato quadrado, personagem em destaque, fundo da obra, texto branco grande na parte inferior, seguindo os exemplos fornecidos pelo dono do bot.

Frases-base recomendadas:
- bomdia
- boatarde
- boanoite
- oi
- feliz
- triste
- raiva
- surpresa
- risada
- vergonha

Não coloque arquivos de voz clonada de pessoas reais sem autorização. Use vozes originais/inspiradas ou áudios autorizados.
